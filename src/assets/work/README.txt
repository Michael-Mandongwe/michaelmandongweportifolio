Drop your client work photos into the matching folder:

  src/assets/work/dynamic-sales-solutions/
  src/assets/work/clothsations/
  src/assets/work/makumbe-avril-holdings/

Any JPG / PNG / WEBP image placed in a folder appears in that company's
gallery on the site automatically — no code changes needed.

Name files in a readable way, because the name becomes the caption:
  linkedin-campaign-launch.png  ->  "Linkedin campaign launch"
  flyer-black-friday.jpg        ->  "Flyer black friday"
